# 🖥️ Pedro Lombardi — Portfólio

Meu portfólio pessoal desenvolvido do zero com HTML, CSS e JavaScript puro. Design responsivo, tema dark/light, suporte a dois idiomas (PT/EN) e animações feitas à mão.

🔗 **[pedrolombardi.vercel.app](https://portfolio-psi-six-7im3e06qol.vercel.app)** ← acesse ao vivo

---

## ✨ Funcionalidades

- **Dark / Light mode** com persistência via `localStorage`
- **Internacionalização (i18n)** — português e inglês, alternância instantânea
- **Typed effect** no hero — sequência de frases animadas letra a letra
- **Partículas interativas** via Canvas API
- **Parallax** no background do hero
- **Fade-in por scroll** com `IntersectionObserver`
- **Formulário de contato** integrado com EmailJS
- **QR Code** do WhatsApp gerado dinamicamente
- **Design responsivo** — mobile-first, menu hambúrguer
